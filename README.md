# 더 경의원 — "고요한 종이" (Quiet Paper)

아이보리 배경과 세리프 타이포 중심의 에디토리얼 레이아웃. 여백을 넓게 두어
오모테산도 특유의 절제된 분위기를 내면서, 로고의 골드 톤을 포인트 컬러로 사용했습니다.

## 실행 방법
```
npm install
npm run dev
```

## 빌드
```
npm run build
```

## 수정 포인트
- `src/index.css` 상단 `:root` 변수에서 색상 조정
- `src/App.jsx`에서 문구 및 실제 사진 경로로 교체 (`.frame`, `.doctor-photo` 등 플레이스홀더 영역)
- 폰트는 Google Fonts CDN(Noto Serif KR, Gothic A1)을 사용합니다
